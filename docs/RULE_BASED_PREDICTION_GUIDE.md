# 基于规则的十二生肖预测功能指南

## 功能介绍

本项目新增了基于规则的十二生肖预测功能，该功能基于2026马年规则、历史开奖数据、遗漏/频率统计等因素，为用户提供下一期生肖的预测建议。

## 核心功能

- **生肖频率统计**：统计每个生肖在历史数据中的出现次数
- **遗漏期数计算**：计算每个生肖距离上次出现的期数
- **五行分布统计**：统计历史数据中五行的分布情况
- **理论概率计算**：基于2026马年规则计算每个生肖的理论出现概率
- **预测建议生成**：基于遗漏期数和频率偏差计算推荐指数，生成预测建议

## API端点

### 基于规则的预测端点

**URL**: `/ml-api/api/rule-predict`

**方法**: POST

**请求格式**:

```json
{
  "history": [
    {
      "period": 2026107,
      "zodiac": "马",
      "number": 49
    },
    {
      "period": 2026106,
      "zodiac": "鸡",
      "number": 22
    },
    ...
  ]
}
```

**参数说明**:
- `history`: 历史开奖数据列表，每个元素包含：
  - `period`: 期号
  - `zodiac`: 生肖（可以是名称或ID）
  - `number`: 开奖号码

**响应格式**:

```json
{
  "success": true,
  "prediction": {
    "top_zodiacs": [
      {
        "id": 6,
        "name": "牛",
        "element": "土",
        "color": "绿",
        "score": 0.9,
        "numbers": [6, 18, 30, 42]
      },
      ...
    ],
    "suggest_wuxing": "金",
    "stats": {
      "total": 5,
      "freq": {
        "马": 2,
        "鸡": 1,
        "兔": 1,
        "牛": 1,
        ...
      },
      "missing": {
        "马": 0,
        "鸡": 1,
        "兔": 2,
        "牛": 4,
        ...
      },
      "wuxing": {
        "土": 2,
        "水": 2,
        "火": 1,
        "木": 0,
        "金": 0
      }
    }
  }
}
```

**响应说明**:
- `top_zodiacs`: 推荐的生肖列表，按得分排序，包含：
  - `id`: 生肖ID
  - `name`: 生肖名称
  - `element`: 生肖对应的五行
  - `color`: 生肖对应的波色
  - `score`: 推荐指数
  - `numbers`: 生肖对应的号码列表
- `suggest_wuxing`: 推荐关注的五行（出现次数最少的五行）
- `stats`: 统计数据，包含：
  - `total`: 历史数据总期数
  - `freq`: 各生肖出现频率
  - `missing`: 各生肖遗漏期数
  - `wuxing`: 五行分布

## 技术实现

### 核心模块

- **zodiac_rule_analyzer.py**: 基于规则的预测分析核心模块，包含以下功能：
  - `analyze()`: 分析历史数据，计算频率、遗漏期数、五行分布等
  - `predict_next()`: 根据分析结果生成预测建议
  - `convert_history_data()`: 转换历史数据格式，使其与分析函数兼容

### 规则说明

1. **2026马年规则**：
   - 本命生肖（马）拥有5个号码：[1, 13, 25, 37, 49]
   - 其他生肖各拥有4个号码

2. **推荐指数计算**：
   - 公式：推荐指数 = 遗漏期数归一化值 * 0.6 + 频率负偏差归一化值 * 0.4
   - 遗漏期数归一化值：当前遗漏期数 / 最大遗漏期数
   - 频率负偏差归一化值：（理论频率 - 实际频率）/ 最大频率偏差

3. **五行建议**：
   - 推荐出现次数最少的五行

前端可以通过AJAX或Fetch API调用该端点，获取预测结果并展示给用户。

## 注意事项

1. **数据格式**：历史数据中的生肖可以是名称（如"马"）或ID（如1）
2. **数据量**：虽然API接受任意长度的历史数据，但数据量越大，预测结果越准确
3. **预测仅供参考**：基于规则的预测结果仅供统计参考，不保证未来结果
4. **与机器学习模型的关系**：本功能与现有的机器学习预测模型并行存在，用户可以根据需要选择使用哪种预测方式

## 故障排除

1. **API返回错误**：检查请求数据格式是否正确，确保history字段是有效的数组
2. **预测结果异常**：检查历史数据是否完整，是否包含足够的期数
3. **服务器启动失败**：确保Flask和必要的依赖已安装
